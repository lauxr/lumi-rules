# 使用方法

先进入 **设置 → Safari → 搜索引擎**，将默认搜索引擎更改为 DuckDuckGo。

在 Safari 内输入「**前缀 + 空格 + 关键词**」，直接跳转到对应网站的站内搜索，无需等待搜索结果页加载。

## 前缀一览

| 前缀 | 目标站点 | 示例 |
|------|----------|------|
| `db` | 豆瓣 | `db 流浪地球` |
| `zh` | 知乎 | `zh iPhone 续航` |
| `wb` | 微博 | `wb 今日热搜` |
| `gh` | GitHub | `gh anywhere` |
| `wk` | 维基百科 | `wk 量子力学` |
| `g`  | Google 搜索 | `g 附近的美食` |
| `gi` | Google 图片 | `gi 壁纸` |
| `b`  | Bing | `b 天气` |

- 不带前缀的搜索不受影响，正常使用 DuckDuckGo
